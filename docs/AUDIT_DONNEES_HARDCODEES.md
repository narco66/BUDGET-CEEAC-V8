## Résultat de recherche

Les recherches ciblées ont couvert les valeurs JSX (`<select>`, `disabled`, `readOnly`, valeurs initiales), options de formulaires, seeders, migrations, routes et règles backend associées. Les corrections ont supprimé les valeurs initiales financières problématiques et le calcul fiscal statique identifié. Les énumérations de code répertoriées ci-dessus sont maintenues volontairement comme règles backend, et non présentées comme des données PostgreSQL administrables.

Le relevé n’affirme pas qu’aucune autre constante métier n’existe dans les 95 fichiers PHP de domaine et 26 écrans TSX. La revue complète reste à poursuivre module par module, notamment pour la configuration des fonctions, exigences documentaires, workflows et règles d’autorité.
